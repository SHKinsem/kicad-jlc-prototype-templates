# 规则说明 / Rule choices

适用范围：KiCad 10、FR4、两层或四层、标称 1 oz、普通通孔、锣边 PCB。这里区分工厂发布的能力与本模板选择的设计余量。

| 项目 | 模板设置 | 依据与范围 |
|---|---|---|
| 最小线宽／线间距 | 全部铜层 0.127／0.127 mm | 设计余量。官方能力总表对 1 oz 双面／多层板列出的下限分别是 0.10／0.09 mm；模板不追求极限。 |
| 默认走线宽 | 0.20 mm | 布线起点，不是电流定额。预设包含 0.127、0.15、0.20、0.25、0.5、1、1.5、2、3 mm。 |
| 焊盘到异网走线 | 0.20 mm | 从原项目保留的设计余量，不应描述为工厂统一最小值。 |
| 两层过孔 | 最小及默认 0.50／0.30 mm | 采用服务指引的常规尺寸（外径／孔径）。 |
| 四层过孔 | 默认 0.45／0.20 mm；外径极限 0.40 mm | 采用服务指引的尺寸；极限外径不作为默认值。 |
| 过孔孔壁到过孔孔壁 | 0.254 mm，同网／异网相同 | 采用服务指引的保守值。 |
| 涉及器件焊盘的孔间距 | 0.45 mm | 铜孔／安装孔等仍需结合具体孔型检查。 |
| 铜到锣边板框 | 0.30 mm | 采用服务指引；V 割需另改为相应规则，不能直接沿用。 |
| 过孔到异网铜 | 铜边 0.127 mm；孔壁 0.20 mm | 保留原项目的显式检查，包括内层；不是全板电压绝缘标准。 |
| 孔环 | 至少 0.075 mm | 继承的几何检查底线；普通过孔另受最小外径和孔径约束。器件插件孔、热焊盘孔、槽孔须按工艺单独复核，不能只依赖此底线。 |
| NPTH 孔径 | 至少 0.50 mm | 保守基础值；圆孔、槽孔、定位孔不能混为一谈。 |
| 丝印到焊盘 | 0.15 mm | 对齐官方丝印到露铜间距要求；模板以焊盘作保守检查。 |
| 文字高度／笔画 | 至少 1.00／0.15 mm | 0.15 mm 笔画为可读性选择；当前能力总表允许 0.10 mm，较旧服务指引写 0.15 mm。 |
| 默认丝印图形线宽 | 0.15 mm | 新建图形的默认值；不会自动修改已放置的标准库封装。 |
| 叠层 | 标称 1.6 mm，铜厚 0.035 mm/层 | 从已使用项目整理的名义结构，不是工厂确认叠层，也不是阻抗计算依据。 |

两个模板都没有 DRC 排除项，也不继承原项目中设为忽略的检查。器件缺失、重复和额外器件检查保留；库差异、悬空走线和单层接通的过孔至少以警告提示。

## 使用时另行决定

- 电源、相线、开关节点、敏感模拟信号的间距、布线宽度与回流路径。
- 工作电压和瞬态电压、环境污染、爬电与电气间隙要求。
- 最终板厚、工厂叠层和铜厚；2 oz、HDI、盘中孔、树脂塞孔、背钻、V 割及半孔不属于本模板默认工艺。
- 插件孔孔环、槽孔宽度、孔边到板边、阻焊桥、器件装配空间等特定要求。

普通制造 DRC 不等同于通过安规、热设计或 EMC 验证。报价和优惠也不能仅由 DRC 文件推断。
